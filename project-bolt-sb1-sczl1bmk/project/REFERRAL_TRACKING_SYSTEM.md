# Referral Tracking & Local-Link Integration System

## 🎯 Overview

FrontDesk AI Pro **does NOT calculate commissions**. Our only job is to:

1. ✅ Capture the unique partner referral slug
2. ✅ Attach it to every checkout and sale event
3. ✅ Forward it to Local-Link so they can pay the right partner

**Commission calculation happens 100% in Local-Link.**

---

## 🔗 How It Works

### 1. Partner Gets Their Unique Link

When a partner signs up at Local-Link and chooses FrontDesk AI Pro to sell:
- Local-Link generates a unique slug (e.g., `taylor-abc123`)
- Partner gets their custom URL: `https://frontdeskaipro.com/?ref=taylor-abc123`
- Partner shares this link on their website, social media, or ads

### 2. Customer Clicks Partner Link

```
Customer clicks: https://frontdeskaipro.com/?ref=taylor-abc123
                                                    ↓
FrontDesk AI Pro captures "taylor-abc123" and stores it
                                                    ↓
Slug persists in localStorage throughout entire journey
```

**Referral slug is captured in these ways:**
- URL parameter: `?ref=xxx` or `?partner=xxx` or `?r=xxx`
- Stored in localStorage: `fdap_ref_slug`
- Persisted through: chat sessions, page navigation, checkout

### 3. Customer Interacts with Bots

The referral slug flows through:
- ✅ Website chat widget
- ✅ SMS conversations
- ✅ Facebook/Instagram DMs
- ✅ Phone calls (stored on lead record)
- ✅ Checkout links generated by AI

**Key:** Once captured, the slug follows the customer everywhere.

### 4. Customer Completes Purchase

```
Customer clicks checkout button
         ↓
Stripe session created with metadata:
  {
    referral_partner_link_slug: "taylor-abc123",
    plan_key: "core",
    workspace_id: "...",
  }
         ↓
Customer pays via Stripe
         ↓
Webhook fires: checkout.session.completed
         ↓
FrontDesk creates outbox_event with referral slug
         ↓
Event sent to Local-Link
         ↓
Local-Link attributes sale to Taylor
         ↓
Local-Link calculates commission based on tier (10/15/20%)
         ↓
Taylor gets paid by Local-Link
```

## 📊 Database Schema

### New Tables

#### `outbox_events`
Queue for sending events to Local-Link
```sql
id                  uuid
created_at          timestamptz
workspace_id        uuid
event_type          text           -- 'sale.paid', 'sale.created', 'addon.activated'
payload             jsonb          -- Contains referral_partner_link_slug + sale data
status              text           -- 'pending', 'sent', 'failed'
sent_at             timestamptz
error               text
attempts            int
```

### Updated Tables

#### `leads`
```sql
referral_partner_link_slug  text    -- Captured from URL or conversation
metadata                    jsonb   -- Additional tracking data
```

#### `workspaces`
```sql
referral_partner_link_slug  text    -- Attribution for workspace
```

#### `checkout_sessions`
```sql
referral_partner_link_slug  text    -- Stripe session attribution
```

## 🔧 Implementation Details

### Frontend: Capture Referral Slug

**File:** `src/lib/referral.ts`

```typescript
// Captures slug from URL params
export function persistReferralSlug(): string | null;

// Reads stored slug
export function readReferralSlug(): string | null;
```

**Auto-capture on app load:**
```typescript
// src/main.tsx
import { persistReferralSlug } from './lib/referral';

persistReferralSlug(); // Called once on app load
```

### Frontend: Pass Slug Everywhere

**ChatWidget:**
```typescript
body: JSON.stringify({
  message: text,
  referral_slug: readReferralSlug(), // ✅ Always included
})
```

**Checkout Button:**
```typescript
const response = await fetch('/api/checkout', {
  method: 'POST',
  body: JSON.stringify({
    plan_key: 'core',
    referral_slug: readReferralSlug(), // ✅ Always included
  })
});
```

### Backend: Store & Forward

**Stripe Webhook** (`supabase/functions/stripe-webhook/index.ts`):

```typescript
// Extract from Stripe metadata
const referralSlug = session.metadata.referral_partner_link_slug;

// Create outbox event for Local-Link
await supabase.from('outbox_events').insert({
  workspace_id: workspaceId,
  event_type: 'sale.paid',
  payload: {
    stripe_customer_id: customerId,
    stripe_subscription_id: subscriptionId,
    referral_partner_link_slug: referralSlug, // ✅ KEY FIELD
    plan_key: planKey,
    amount: amountTotal,
    currency: 'usd',
  },
  status: 'pending',
});
```

## 🔄 Local-Link Integration

### Option 1: Push (Recommended)

FrontDesk pushes events to Local-Link automatically.

**Endpoint:** `supabase/functions/locallink-send-outbox`

**How it works:**
1. Run on schedule every 2-5 minutes
2. Fetches pending outbox events
3. POSTs to Local-Link API
4. Marks as `sent` on success
5. Retries up to 5 times on failure

**Trigger via cron:**
```bash
# Every 5 minutes
curl -X POST "https://your-project.supabase.co/functions/v1/locallink-send-outbox" \
  -H "Authorization: Bearer YOUR_SERVICE_ROLE_KEY"
```

**Required Secrets:**
- `LOCALLINK_INGEST_URL` - Your Local-Link webhook endpoint
- `LOCALLINK_INGEST_SECRET` - Shared secret for authentication

### Option 2: Pull

Local-Link pulls events from FrontDesk on their schedule.

**Endpoint:** `supabase/functions/locallink-commission-feed`

**How it works:**
```bash
# Local-Link makes authenticated request
curl "https://your-project.supabase.co/functions/v1/locallink-commission-feed?since=2024-01-01T00:00:00Z" \
  -H "X-LocalLink-Secret: your-shared-secret"
```

**Response:**
```json
{
  "success": true,
  "count": 25,
  "events": [
    {
      "id": "...",
      "event_type": "sale.paid",
      "created_at": "2024-01-15T10:30:00Z",
      "payload": {
        "referral_partner_link_slug": "taylor-abc123",
        "stripe_customer_id": "cus_...",
        "stripe_subscription_id": "sub_...",
        "plan_key": "core",
        "amount": 15400,
        "currency": "usd"
      }
    }
  ],
  "next_cursor": "2024-01-15T10:30:00Z"
}
```

## 🚨 Critical Points

### ✅ DO

1. **Always capture referral slug** from URL on first visit
2. **Always pass referral_slug** in checkout requests
3. **Always store in Stripe metadata** for audit trail
4. **Always create outbox event** on successful payment
5. **Test the full flow** with a real partner link

### ❌ DON'T

1. **Don't calculate commissions** in FrontDesk (that's Local-Link's job)
2. **Don't lose the slug** during page navigation or chat sessions
3. **Don't skip attribution** even for free trials or demos
4. **Don't expose Local-Link secrets** in client-side code
5. **Don't forget to schedule** the outbox sender

## 🎉 Summary

**What FrontDesk AI Pro Does:**
1. Captures partner referral slug from URL
2. Stores it throughout customer journey
3. Includes it in Stripe checkout metadata
4. Creates outbox event on sale completion
5. Sends event to Local-Link (push or pull)

**What Local-Link Does:**
1. Receives sale events with referral slug
2. Looks up partner by slug
3. Calculates commission based on partner tier
4. Records commission in partner dashboard
5. Handles all payout logic

**Result:** Partners get paid correctly, automatically, with zero manual tracking! 🚀
