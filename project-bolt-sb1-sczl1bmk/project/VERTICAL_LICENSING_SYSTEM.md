## 🔧 HOW IT WORKS

### For Admin (You):

1. **Navigate to Admin Dashboard** → Vertical Licensing tab
2. **Click "Create License"**
3. **Select vertical template** (e.g., CleanDesk AI)
4. **System automatically:**
   - Generates unique license key (format: `XXXXXXXX-XXXXXXXX`)
   - Creates license record
   - Sets up default configuration
   - Assigns subdomain
   - Activates bot preset for that industry

5. **Share license with partner/franchisee**
6. **Track revenue and usage** in real-time

### For Licensee (Partner/Franchisee):

1. **Receives license key and subdomain**
2. **Logs in with their credentials**
3. **Sees their branded vertical** (CleanDesk AI, not FrontDesk)
4. **All 38 bots available** with industry-specific training
5. **Customizes branding:**
   - Upload logo
   - Set brand colors
   - Custom CSS
   - Welcome messages
   - Support contact info

6. **Sells to their customers** in their industry
7. **You track revenue** and charge licensing fee
