## 🔌 INTEGRATION POINTS

### Customer Usage:
```typescript
// Call any bot from frontend
const response = await fetch(
  `${SUPABASE_URL}/functions/v1/bot-orchestrator`,
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${SUPABASE_ANON_KEY}`,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      workspaceId: 'workspace-uuid',
      botNumber: '1', // Bot #1-27, A1-A11
      action: 'execute',
      data: { /* bot-specific data */ },
      leadId: 'lead-uuid' // optional
    })
  }
);
```

### Response Format:
```json
{
  "success": true,
  "bot": "AI Business Brain",
  "result": {
    "action": "business_knowledge_retrieved",
    "businessName": "My Business",
    "context": "...",
    "personality": "professional and friendly"
  },

}
```
